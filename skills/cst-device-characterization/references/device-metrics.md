# 按器件选择指标与图形

先写测量映射：物理端口、输入/输出频率、端接、输入功率口径、控制状态和归一化。Sij 始终表示由 j 激励到 i 响应；控制偏置符号不定义传播方向。

| 器件 | 工况与主要指标 | 按已有数据选择的图 |
|---|---|---|
| 调制器 | 控制形式、载波及边带；调制深度、插损、响应带宽/速度；调制深度注明电压/场/功率及公式 | 状态传输、输出包络、调制响应、边带谱、实际结端波形 |
| 隔离器 | 对应正反输入采用一致源、终端与控制条件；同频传输、反射、带符号方向差及联合工作带 | 两向传输、对应反射、方向差、频谱及功率去向 |
| 混频器 | 显式 RF/LO/IF 或其他频率映射、边带及混频阶数组合；转换增益/损耗、端口隔离、杂散与需要时的压缩 | 指定转换通道响应、输出谱、LO/输入扫描、端口泄漏 |
| 开关 | 明确每个偏置/控制状态及端接；通态插损、断态隔离、回波和按约定门限的切换时间 | 状态传输/反射、控制与输出波形、状态对比 |

隔离器的方向差注明所采用的差值及符号，不能把优势方向悄悄交换。仅比较通态与断态不等于非互易性；场局域或波形不对称也不单独证明隔离。

混频器转换功率增益定义为指定输出频率/边带功率与被测输入功率之比，再取 10 log10。明确输入采用可用功率、入射功率还是净接受功率；转换损耗采用相反符号。同频 S21 不等于跨频转换增益。电压比仅在相应阻抗及归一化已核对时才可转换为功率比。LO 供能单列，不混入 RF 分母。

两端口同频结果可将 S21/S12 配对、S11/S22 配对；多端口、差分或跨频器件按真实测量映射组织，不强套该布局。指标根据器件物理定义，不能只换图名。

各频率、源功率、状态或方向缺项单独标注。峰值只对已采样范围成立；联合合格样点段不自动认证连续带宽或端点。阈值、响应时间定义和误差预算来自本次任务，不设置固定器件目标。
