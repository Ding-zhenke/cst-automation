# 表示选择、寄生归属与连接

明确选择理想机理替代、集总非线性结、含封装 SPICE/等效网络，或三维封装加结接口。标注替代假设，不自动等价于实体器件。

寄生归属表逐项列结电容/电导、串联电阻、引线电感、焊盘电容、接触和回流，由模型卡、电路或 EM 谁表示。已有封装寄生不能再在电路/三维中加一次，裸结也不能遗漏封装。频率、温度及额定条件来自可靠器件资料，不从单一击穿字段推断动态额定。

接口替代预定非线性区域，不能与已有导电路径并联短接。检查真实金属连通、接触、间隙、离散端口跨接及参考面。薄层简化或实体拆分属于模型改变。

接口表包括端口 ID、位置、正/负端、参考地、阻抗、去嵌参考面、A/K 与块引脚。旋转外观、名称或旧图不证明极性；若端口正端在 K，则 Vport 与 VAK 符号相反，探针及电流一起校准。

核对偏置源—器件—回流闭环与 DC 参考。不能为消除浮置警告随意接地，低频 SNP 拟合不自动提供正确 DC 拓扑。加探针后检查网络，避免短接或改变连接。

直接加载与端口替代对照保持同一物理区域、参考面、阻抗和寄生归属。模块拆分丢失的空间耦合不能由端口连接恢复，整体还查互耦、回流与边界。

同一拓扑可在同一工作工程组织 EM、DC、HB、瞬态及后处理。源幅值/频率/状态改变不自动是新拓扑；连接关系改变时建立明确版本及接口映射。
