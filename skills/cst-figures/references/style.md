# 可配置科研绘图样式

当前用户要求、目标期刊和已有项目样式优先。以下为阅读默认值，不是所有期刊的强制规范，也不包含器件参数。

| 项目 | 默认 |
|---|---|
| 多曲线/多面板宽度 | 15 cm，按面板布局调整高度 |
| 单图/投稿尺寸 | 按实际信息量与期刊要求覆盖 |
| 英文与数字 | Times New Roman；缺失时明确使用已安装替代字体 |
| 中文 | Microsoft YaHei 或其他完整覆盖字符的已安装字体 |
| 字号 | 基础 10.5 pt；轴标和标题约 11 pt，刻度和图例约 10 pt |
| 线宽 | 约 1.5 pt，可按最终尺寸调整 |
| 背景/图例 | 白底、无框图例、无默认网格 |
| PNG | 300 dpi，矢量导出保留字体与线条 |

默认离散色循环为蓝 #0072B2、朱红 #D55E00、绿 #009E73、紫 #CC79A7、橙 #E69F00、深灰 #333333。它是本插件的可配置配色方案，不宣称复刻某个私人项目。相同物理量跨图同色，对照再用线型/点型区分；不能只靠红绿区分。

强度等非负量使用顺序色图，例如 viridis；有符号量可用以零为中心的发散色图，周期相位使用周期色图。色条写量及单位；比较图共用色标，或明确解释差异。场图保留真实坐标比例。

使用随附 assets/research.mplstyle 的实际路径，在 `with plt.style.context(style_path):` 内创建图。style_path 指当前已安装插件的该资产；不使用开发机路径。图宽可以由 `width_cm / 2.54` 换为英寸。字体缺失应核对系统字形，不自动下载字体或提交私人配置。

数学公式、dB、角度及 SI 前缀统一；不把运行编号改标签冒充频率。展开相位说明处理轴和参考，弱信号保留掩码；dB 数组不二次取对数。论文图在最终缩放尺寸下检查字号，而非只查看高分辨率预览。
