# 材料、边界与端口

## 材料前置检查

创建实体、曲线成体或改变材料赋值前，维护本次构建的材料依赖表：**精确材料名 → 使用对象 →
来源及物性/参数/单位 → 当前工程已存在或本次创建/导入 → 准备阶段及检查结果**。
覆盖基板、金属、薄层、填充体和布尔工具体；几何 API 的 `material=` 与 `change_material`
只引用材料名，不负责定义它。后续阶段沿用已检查且未改变的定义，新增或改变依赖时更新，
不为每个基础体重复制表或创建材料。按以下顺序处理：

1. 区分 CST 内置可直接引用的 `PEC`、`Vacuum` 与工程材料。`Copper`、`Quartz`、
   `Gold` 等名称不因在材料库、旧工程或 Python 字符串里出现，就已存在于当前工程。
   新建空工程须重新准备所需工程材料；已有工程先核对真实定义，不能仅凭同名覆盖物性。
2. 缺失材料先用现有 API 创建或导入，物性有参数依赖时先定义参数。普通材料用
   `create_material_custom`，张量/旋磁材料用对应接口；预设和库文件入口限制见
   [材料与单位](model-operations.md#材料与单位)。创建名、导入后的实际名称和几何引用名
   必须完全一致，保留空格、括号及文件夹限定名。
3. 需要创建或导入材料时，材料准备与依赖几何分阶段提交；全部使用内置或当前工程已核对的
   材料时，无须空的材料写入阶段。检查材料阶段的任务状态、结构化失败和实际 CST 消息，
   失败或状态未知时先定位，不能继续提交几何。返回 `None` 或 Python 未抛异常本身不证明
   创建成功。具备原生材料查询时核对定义；缺少读回时保留该证据限制，不虚构查询 API，
   也不把提交的 history 文本当成原生物性读回。实体检查返回的材料名只证明赋值，
   不等于该材料完整物性的读回。已保存的 SI 磁旋材料可用
   `cst_automation.material_snapshot.read_gyrotropic_material(project_path, material_name)`
   从该工程的 Model.mif 核对两项角频率、阻尼和偏置方向，注明来源为已保存的缓存快照。
4. 通过准备阶段后，才在实体创建、曲线成体或重新赋值时引用该名称；几何阶段再核对
   实际实体材料。遇到“材料不存在”先修正生成器的定义名称和先后顺序，按原任务状态恢复，
   不在末尾补定义后盲目重放，也不临时替成 PEC/Vacuum 来掩盖失败。

例如空工程中，先创建名为 `Quartz` 和 `Copper` 的材料并检查材料阶段，再执行
`square(..., material="Quartz")` 和 `square(..., material="Copper")`。
如果创建的是 `Copper (annealed)`，实体就引用 `Copper (annealed)`，不能缩写成 `Copper`。

## 物理表示与端口审阅

选择 PEC、有限电导率、介质、薄层或张量时说明物理表示和求解器兼容性。显示颜色不是
材料赋值。全复数 epsilon/mu 张量及独立 U/V 轴用 `create_material_full_tensor`；
`create_material_tensor` 仍是标量 epsilon 的便利接口。核对系数、符号、坐标轴和实体
赋值；内置宏 Load Settings 读取其 INI，默认对话框不能充当已有材料读回。

明确每个边界面、背景性质与外扩空间；对称/周期边界须与几何及激励一致。端口核对
编号、位置、朝向、范围、模式、极化和参考面；先选择自由放置/拾取波导端口、离散
端口或集总元件的正确 API。场监视器与传输曲线输出分开设置。

微带断口、焊盘或带线到地具有明确接触宽度时，离散端口与集总 RLC 默认用两条
相对接触边定义面。实际接触宽度由焊盘或器件决定。针尖、键合线端点等局部接触
可按物理馈电方式使用点定义。选边和参数化示例见[微带接触边](model-operations.md#微带接触边)。

离散端口坐标/阻抗/长度使用所属会话 `inspect` 的 `discrete_port_ids` 有界原生读回；
调用示例和证据边界见 [端口原生读取](model-operations.md#离散端口原生只读)。
不为获得缓存而保存、建网格或重建，不从默认 50 Ω 推断真实端口阻抗。

替换已有端口使用 `replace_port_with_waveguide`，明确目标编号、原类型和保留端口；
提交前读 [端口替换限制](model-operations.md)。必须使用具备
`port-replacement-readback-v1` 的 worker；不能重启正在求解的 worker 来升级。
离散 edge→face 的备用路线使用显式 `create_discrete_face_port` 与有序拾取边；先读
同一引用中的面端口说明，记录并核对原属性，不能把创建默认值误当成自动保持。

阻抗要求拆成四项：EM 端口参考阻抗、电路源/负载阻抗、传输线几何阻抗、导出矩阵
归一化阻抗。设置端口数值不会改线宽；重归一化数据也不会改变实际匹配。基板厚度/
材料改变后审查端口馈线、渐变两端及负载端连接，并保留用户指定不变的主线尺寸。
原有引线内的渐变默认替换该段，不无依据另加长度；终端电阻不自动变成新增端口。
线宽公式只给初值，实际匹配由当前 EM 结果验收。
