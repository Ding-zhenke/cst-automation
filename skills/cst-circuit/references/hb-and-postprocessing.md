# HB、原生扫描与结果刷新

按安装版本核对 cst_solver.circuit.native 的 HB、Parameter Sweep、复谱提取及结果写回入口。以实际源码确定签名；没有可靠接口时报告缺项，不复制私人脚本当通用 API。

HB 基频、阶数、源幅值定义和任务局部单位明确记录。保留表达式依赖，不把接口求值后的固定属性描述成自动联动。矩阵覆盖检查所有保留混频组合及低频/DC需求；覆盖充分不等于拟合或截断收敛。

## HB 运行前的放行门槛

此门槛用于已授权的 HB/父扫描运行；只配置或离线任务只准备证据清单与编排，不启动求解补验收。

1. **读实际需求。** 读取目标 HB 的实际 tones、阶数、Box/Diamond scheme、局部单位及参数表达式在本次工况的值。令保留整数混频索引集为 `K`，需求上限为 `max(k in K, abs(sum(k_i * f_i)))`，并包含 `0 Hz`。Box 的上限为 `sum(n_i * f_i)`，`n_i` 为各 tone 的最大阶数；完整父扫描按实际参数域求最大需求。Diamond 按当前版本规则求保留集；无法精确枚举时，使用已核实包含该集合的 Box 上界并记录保守性。scheme、表达式或阶数不明时停止，不凭 RF 频段或绘图上限估算。
2. **逐块读实际覆盖。** 清点参与 HB 的所有频率相关被动块与链接数据。每块记录实际块名、文件/矩阵来源、频率单位、有效区间、实际零频样本/模型端点、来源参数与运行身份。文件用实际频轴，链接模型用可核对的原生有效范围与对应数据；配置声明不能替代数据。任一块缺失、覆盖 unknown、下限高于零或上限不足，均不放行 HB。区间包含全部保留混频是必要条件，仍须检查样本/插值有效性与数据质量。
3. **分别验收来源。** 参考 NPORT 与新链接 EM 各自完成上述清点。一个文件支持 DC，不证明另一个块支持 DC；旧拓扑、旧几何或旧参数的合格矩阵不证明当前矩阵合格。全局 `fmin=0`、求解器范围、请求的外推选项和已有曲线均不是实际覆盖证据。
4. **先代表工况。** 拓扑或 EM 数据改变后，从已批准扫描中选择有界正向、反向代表工况；先检查当前 DC 工作点及实际器件端电压，再检查 RF 实际入射量、端口/负载匹配与归一化，最后核对实际谱线、零频分量、频轴及 HB 收敛。保持源条件、方向定义和截断设置不变。只有两方向检查满足调用方明确的验收条件后，才运行完整父扫描。代表点通过只证明该范围，不代替全扫验收。
5. **首个失败即停止。** 初始化失败、原生错误或数值验收失败，立即停止提交后续参数组；对已启动父任务按已核实的正常停止方式处理，不强杀或重复提交未知状态任务。保留首个上游错误、任务/工况/运行身份及原生日志。依赖该失败输入的同级模板标记 skipped/upstream failed，不运行它们制造 missing-node 级联；本轮有效输入须匹配当前工况和运行身份，不得用旧结果冒充。修复后重新通过代表工况才恢复后续组。

调用方的放行记录至少包含：实际 HB 需求、每块覆盖及来源、代表工况的 DC/RF/谱线验收、首个错误与停止/跳过决定。缺证据即记录 blocked/unknown 和具体缺项，不提升为成功。

### 接口与原生任务的边界

- `configure_hb_task` 配置 tones/scheme，不读取或验收被动数据覆盖。`configure_hb_postprocessing_chain` / `inspect_hb_postprocessing_chain` 配置/检查启用状态与 HB→Post 顺序，不实现上述 DC/频率门槛、首错停止或模板输入验收。现有高层接口没有通用“读取所有被动模型有效频域并自动放行”的入口；原生能力须按块类型和当前版本核实，不能虚构 getter 或把 `GetFile` 路径当作覆盖证明。
- CST 官方帮助 `DES/analysis/simulation/tasks/using_a_spectral_lines_task.htm` 定义 Box/Diamond 混频规则；`DES/analysis/simulation/tasks/simulationtasksequence.htm` 说明 sequence 的 **Abort if subtask fails**。依赖链使用该类原生 sequence 时核对并启用该设置，保留实际读回；它不自动证明 Parameter Sweep、其他父任务或所有模板都具有同样行为。未核实设置入口时报告缺项，由调用方显式串行运行与条件调度，不猜测 `SetProperty` 名称或无条件启动完整父扫描。
- 对已有正在运行的父任务，先查状态和停止能力；无法保证组间停止时先报告风险与缺项，不把 Python 捕获异常等同于原生父任务已停止。若模板仍由 CST 触发，模板入口须在读取节点前验当前运行输入；没有该保护时，不宣称已具备自动跳过能力。

### 低频推导零端点的证据边界

从实际低频样本拟合或外推到 `0 Hz` 的端点属于近似。保留低频采样频轴、复数矩阵、来源运行/参数、拟合方法及阶数、拟合/留出残差，并在目标范围检查无源性；对本应互易的被动模型另查互易性，说明参考阻抗和误差判据。只有一个近零样本或人为添加零频行不足以证明质量。覆盖通过后仍须在当前拓扑重新核对实际 DC 工作点和器件端电压；不能称作独立 DC 电磁求解或用参考 NPORT 的旧工作点代替。证据不足时停止并列缺项，不自动修改数据或扩大求解范围。

原生 Parameter Sweep 与 Python 逐点 run_parameter_study 分开；后者按[参数研究](parameter-studies.md)保存不可覆盖的快照。原生扫描核对父子任务、参数单位和实际结果集合。

复谱记录任务、树路径、运行身份及完整频轴。原生波形和谱线重建校准 DC、峰值/RMS、正负频率约定与公共时钟，不普遍硬编码倍数。

Results 只替换本次拥有的叶节点；删除可能连带删除信号文件时，先删旧叶，再写新 .sig，最后添加。dB/展开相位按实数保存，不重复取对数或折回主值。保存后逐点核对坐标、单位、数值及标签。

固定 Results 是快照，不能假设 Update HB 自动重画。用户要求改参后自动刷新且保留历史时，须由已绑定后处理自动生成每参数曲线；原生参数存储未打通时使用独立叶与完整复数归档，不能让用户每轮手动导出。见[自动刷新与参数历史](../../../docs/guides/hb_parametric_storage_and_length_results.md)。已有模板源码更新不表示首次自动绑定可用，暂存/语法通过不等于原生执行通过。不为补图擅自求解。
