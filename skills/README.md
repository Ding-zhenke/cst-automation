# 通用 CST 插件的九个 skill

按任务选择相应入口，详细资料仅在相关时加载。用户当前指令和目标仓库约定优先。

| Skill | 场景 |
|---|---|
| [cst-sessions](cst-sessions/SKILL.md) | 会话、工程归属、中断恢复与去重 |
| [cst-modeling](cst-modeling/SKILL.md) | 几何、材料、端口、预览与重建 |
| [cst-simulation](cst-simulation/SKILL.md) | EM 设置、网格、求解与运行证据 |
| [cst-circuit](cst-circuit/SKILL.md) | 电路、场路、HB/瞬态及参数研究 |
| [cst-results](cst-results/SKILL.md) | 复数结果、历史工况、读取与导出 |
| [cst-diagnostics](cst-diagnostics/SKILL.md) | 环境、SDK、弹窗及失败诊断 |
| [cst-diode-loading](cst-diode-loading/SKILL.md) | 二极管加载、寄生归属、偏置及数值判断 |
| [cst-device-characterization](cst-device-characterization/SKILL.md) | 调制器、隔离器、混频器及开关的指标与报告 |
| [cst-figures](cst-figures/SKILL.md) | 科研图、结构预览及共享样式 |

指令唯一源码位于本目录。插件只打包明确审阅的公共参考资料与样式；项目参数、设备模型及运行数据留在目标项目。安装与构建见[插件指南](../docs/guides/codex-plugin.md)。
