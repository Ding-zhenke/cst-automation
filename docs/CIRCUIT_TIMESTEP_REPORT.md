## Python 封装范围

`0.2.0.dev0` 已实现 `setup.circuit` 的原理图、元件属性、连接、指定任务、结果读取、依赖清点及 service/MCP 路由。普通导入不加载 CST SDK。接口实现与实机验收是两件事：通用映射、缓存、外部工程搬运及非线性仍按各自证据判定。

本报告的实际时间步控制和详细原生读回使用验证脚本调用 CST SDK。后续新增的 `app.configure_em_time_settings` 将稳定因子和每步输出请求封装为高层入口，但只取得离线验证；没有将本报告的原生脚本证据提升为新封装的实机验收。列出二极管/SPICE 类型也不等于其联合求解已验收。

功能收尾另新增 `configure_transient_task`，整理 DS 模式、带单位时长、采样顺序、请求步长及最大频率，显式接入 service/MCP。它不验证三维实际时钟、不自动求解；组合接口实机验收按用户新优先级后置。当前能力以 [公共协议](PUBLIC_API.md) 和 [指南](guides/circuit_cosimulation.md) 为准。

## DS 插值警告的定位

此前 8001 个手工输出点的间隔为 5 ps，DS 提示其预估最大步长为 44.9548 ps。固定步长请求的读回不能证明联合积分实际采用该值。

本机官方帮助明确说明：

- DS `Simulated` 采样保存全部实际仿真时间点，Manual 是独立的绘图采样。
- 瞬态场路联合的步长通常由三维网格决定；本次 DS 日志实际采用一阶 Backward Euler。
- `Solver.AutomaticTimeSignalSampling False` 让三维端口时域结果保存每个时间步。
- `Solver.TimeStepStabilityFactor` 乘到三维允许的时间步上。

来源及原文件 SHA-256 保存在 `official-time-control-evidence.json`。本次选用 Simulated、关闭三维输出抽点，DS 不再输出插值警告；没有过滤或放行该警告，原日志验收谓词保持不变。将 44.9548 ps 归因于手工绘图检查使用的预估值，是根据官方说明及新旧实测对照作出的判断；没有冒称取得 CST 内部实现源码。

## 实际积分步长与收敛

批准的三维几何、材料、端口及 23,868 单元网格保持一致。三档运行的网格文件 SHA-256 相同，三维历史除稳定因子外相同。每个运行都保存独立工程、运行 token、新的 DS/EM 完成日志、原生 SUCCESS、完整端口电压/电流及 CSV 元数据。

| 稳定因子 | EM 日志实际步长 / ps | DS 全部实际时间点的间距 / ps | 证据目录 |
|---|---:|---:|---|
| 1 | 0.8189415936 | 0.8189415936 | `raw-1` |
| 0.5 | 0.4094707968 | 0.4094707968 | `raw-half` |
| 0.25 | 0.2047353984 | 0.2047353984 | `raw-quarter-b` |

DS 实际时间轴与三维日志相符，且随稳定因子减半；不是仅增加绘图点。两侧保存输出间隔均小于 5 ps，覆盖 40 ns，稳态比较固定为 20–39.99 ns，不拟合符号、不自由平移时间。

相邻时间步对照中，四条 EM 端口电压/电流的最大基波幅值变化 **0.05042%**、相位变化 **0.03357°**、波形 NRMSE **0.07718%**。幅值变化低于既定 2% 门槛；额外的相位 3°、波形 1% 检查也通过。

25/50/100 Ω 负载复验均无 DS 警告，严格公共运行契约为 succeeded。相对独立裸线网络参考，最大幅值误差 **0.16671%**、相位误差 **0.19072°**，低于 3%/3°；两侧端口波形最大 RMS 差 **0.68278%**，低于额外保留的 1% 检查。改变负载后两端探针均有反馈。详见 `linear-timestep-acceptance.json` 和各目录的 `linear-acceptance.json`。

## 普通网络瞬态对照

原 0.1–5 GHz 网络用于普通瞬态时，DS 正确警告其从 100 MHz 起的数据被用到 DC，结果保留 unverified，没有屏蔽该警告。

另在 `network-transient-dc-control-b/` 中以同一几何、同一网格补算 **0–5 GHz** 裸线网络，取得有限的 DC S 参数，再运行 `circuit simulator=cst` 的普通瞬态任务。该任务使用二阶 Gear、800 fs 恒定步长和向量拟合，日志无警告，公共契约 succeeded。DS 任务前后三维日志/输出文件摘要不变，证明对照任务复用网络；真实联合运行则有新的 Network co-simulation 三维开始/结束记录。

对照与真实联合的稳态最大幅值差 **0.07698%**、相位差 **0.18437°**、波形 NRMSE **0.33059%**。记录为 `network-transient-control-acceptance.json`。DC 补算是独立对照副本，没有改写三档时间步、三种负载或非线性样例的既有输入。

## 独立三维局部场读回

`probe-load50-b` 与 `probe-load100` 在每个端口 0.8 mm 间隙中布置 32 个固定中点 Ez 探针，原生场曲线独立于离散端口结果树。探针使网格成为 40,716 单元，因此作为单独诊断网格记录；两种负载的网格摘要一致，不混入上述 23,868 单元时间步矩阵。

根据本机官方端口方向和网格电压约定，固定采用 `U_CST = +∫P1→P2 E·dl`，以 SI 单位和预先确定的中点权重积分，不拟合符号、比例或时延。对照 DS，最大幅值误差 **0.02130%**、相位误差 **0.08690°**、波形 NRMSE **0.15304%**；负载变化的积分电压与电路变化也一致。完整 64 路原生场数据、坐标读回及哈希保存在各目录的 NPZ/JSON 中。

`full-v4-acceptance.json` 汇集时间步、普通网络对照和局部场三份通过报告，独立只读审查接受 V4 物理门槛。先前官方 SDK 独立构建参考满足 V2 的“UI/官方参考”选项；新增 UI 尝试没有成功，单独保留 unverified。

## 非线性模型封装校准

发现并修复了内置二极管的特殊读回路径：CST 支持写入 `Model Type`，但该字段不支持普通 `GetProperty`。当前仅对已校准的 Berkeley SPICE 模型，从实际原生类型、完整十五项名称/类型枚举确认身份，并明确标注 `documented_native_property_schema`；不把请求枚举冒充读回值。所有参数的实际值、类型、单位均记录。迭代结束标志经实机确认是三个空字符串的 tuple；其他异常、缺项或额外项继续失败。

模型选择始终先执行，普通参数最后统一从原生状态读回；无量纲参数先核对空单位，不调用 CST 不支持的局部单位设置。`v5-wrapped-model-readback-c` / `v5-wrapped-model-reopened-c` 已验证写入、保存和重新打开，确认 IS=1e-14 A、N=1、RS=1 Ω、CJO=0 F、TT=0。此项只证明输入状态，不证明非线性求解通过。

校准副本中另一个无连接的 SPICE 块引用缺失文件，因此该记录只用于内置 D1 的输入核验，不能当作完整 SPICE 依赖或可运行工程证明。非线性 SPICE 复测须在新副本中写入实际存在的模型文件，并记录文件摘要及实际模型名。

## 窗口与证据边界

读到了同属本次 CST 进程、无按钮、正文为 `Saving model / 100%` 的实际保存进度窗口；未点击。其完整已知正文可作为进度识别，但空正文、读取失败、不完整/截断或带交互按钮的窗口继续阻塞。窗口在 UIA 读取期间已消失时重新核验当前可见性，避免把过期快照报告为仍可见的阻塞窗口；这不是 SDK 或求解成功依据。

原保存失败会话关闭后，使用新的副本目录重新打开并执行；原失败目录不提升等级。没有对未知弹窗盲点。求解完成仍独立依赖原生状态、任务归属、新日志和保存结果。

本报告的线性时间步结果不证明非线性、完整能量守恒、外部链接搬运或通用端口/模态映射。已开展的非线性复算及尚未通过的接口电流检查另见 [非线性排查](CIRCUIT_NONLINEAR_REPORT.md)，不能用单项波形收敛覆盖其失败。
