# 通用电路参数研究设计

用户已在 2026-10-30 确认方案并授权执行。面向拓扑不变的纯电路及同工程 EM＋电路设计，支持任意已有的网络电路任务（包括 HB、AC、S 参数、普通瞬态），不写入隔离器专用量。

## Approaches
- 仅 skill：无法统一执行和保存，弃用。
- 仅原生扫描配置：已有配置接口可复用，但不提供逐工况归档和 EM 来源核验。
- 采用 API 编排＋原生结果＋不可覆盖归档；skill 固化规则。先用明确的逐点序列执行，不冒充原生 Parameter Sweep，也不修改已有扫描任务。

## Contract
- 参数定义显式声明 scope=em/circuit、unit；可选 block/property 将电路参数绑定到元件属性。不带 block 的参数必须已存在于相应原生参数表，数值使用声明的原生单位，由调用者确认与工程一致。
- 每个 point.values 完整指定所有研究参数，有限实数；支持重复点，case ID 包含序号；每次执行生成唯一批次。
- EM 可选；存在 EM 参数必须提供 EM 结果路径和实际 run ID。第一版保守地对 EM＋电路每点重算 EM，暂不自动复用缓存。不推断外部 EM 块映射，不支持瞬态双向联合；后者继续使用现有 transient_cosim 接口。
- 参数预检、任务和结果归属、所有点的元件值预检完成后才开始写入。每点设置参数并重建 EM，保存，运行带证据的 EM 求解，再调用现有 circuit.run_checked；未验证状态停止，不拿旧曲线补齐。
- 先保存完整复数原始数组及单位、参数、EM 摘要和运行证据，再为各工况向原生 Results 写 magnitude/real/imag/phase 曲线；按结果量/分量组织比较目录。保留既有原生任务结果，不声称所有历史原生 run 都不可变。
- study.json 为批次清单；每点独立 case.json 和复数 CSV，存于工程 Result/DS/Studies 下。调用者须保留整个工程和结果目录；未做原生重开验证前不承诺单个 .cst 二进制已封装全部归档文件。
- StudyResult 提供过滤、跨工况比较和保存结果读回核验；校验参数、单位、复数与来源摘要。原生重开验收独立于离线测试，第一版不主动打开/关闭现有 CST 窗口或发起设备求解。

## Constraints and delivery
Python >=3.9；沿用 cst_solver / cst_automation / tpc_service / cst_mcp，无新依赖。现有接口兼容。服务和 MCP 显式注册，始终进入唯一 worker。非法输入不打开 SDK；失败保存部分清单，不自动重试。拓扑变化作为不同设计。

## Acceptance
离线覆盖纯电路、EM 顺序、重复点、无覆盖归档、旧 run 0 不作为历史、失败中止、过滤/单位、写回读回和服务队列。实际 CST 保存关闭重开、HB/AC/瞬态兼容性仍列为未执行的独立实机验收，不以模拟对象证明。
