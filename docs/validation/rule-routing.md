# 整库规则与本机插件验收

验收面向首次执行环境、任务分派、工程授权、证据保全和发布内容。本文中的请求均为离线情景；独立波导、器件工程、CST 和 ADS 求解均无须启动。[逐项迁移对照](../RULE_MIGRATION.md)

| 模拟请求 | 应采用的路径 | 必须能区分的许可或证据 |
|---|---|---|
| 读取已经导出的 CSV，画传输曲线 | 结果读取 → 按需绘图 | 无须许可证，可在隔离环境读表。使用文件中的方向、单位和工况，不能推定工程已收敛。 |
| 从冻结的已保存 CST 工程读原生结果 | 结果读取 → 原生只读 | 首次 SDK 调用即用许可宿主；优先使用 `allow_interactive=False` 打开保存副本，核实 Run ID 与参数。无需打开交互工程或启动求解。 |
| 对已审阅的现有工程明确要求运行一次 EM | 仿真 → 单次运行 | 核对绝对路径、现有任务和授权，非交互进程后台启动。单次可直接 `setup(path)`、`app.run()`，已有受管任务遵守原状态。验收看日志与真实结果。 |
| 仅配置并保存服务器使用的参数扫描 | 参数研究 → 配置与交接 | 核对扫描轴、取值和默认参数。配置检查可能重建，先保全所需结果，核查恢复与保存；交接到此结束。本地执行与导出分别需要相应请求。 |
| 用户修正参数后继续多轮 EM→HB | 隔离器流程 → 会话清单 → 各阶段技能 | 更新工程清单，核验当前输入的 EM、同工程静态 SP、匹配 SNP 及其身份。提交前检查和受管执行检查各自生效。HB 默认 ADS；只有明确要求才启动 CST HB。 |
| 写入中断，返回继续原任务 | 会话 → 任务和工程生命周期 → 必要时诊断 | 使用原引用、PID、worker、任务与回执恢复。状态不能确认时继续取证，不重新提交未知写入；关闭单个过程工程与退出整个环境有各自条件。 |
