# 2026-11-19 建模材料前置检查

本次维护只修改 `skills/cst-modeling/` 的入口和引用，不改变 Python API、会话 worker
或工程。材料实现依据为 `cst_solver/material/materials.py`，几何引用依据为

## 问题与修正

原分阶段指引虽要求先材料再实体，但把“最后材料赋值”列为收尾，未明确首次引用前的
材料准备检查。原材料引用还把仅支持三个固定预设的 `new_material/create_material`
描述为库材料入口，可能将未创建材料的 `None` 返回误判为成功。

现明确：维护材料依赖表，先创建或导入缺失定义、检查材料阶段，再创建引用这些名称的
实体。补充三个预设的精确名称、`material_not_preset` 失败行为、库枚举与工程定义的
区别，以及实体赋值与完整物性读回的证据边界。内置和已核对材料复用，无须空写入阶段。

## 离线行为验证

修改前的独立走读者能从原有规则推导出正确顺序，也指出首次引用与末尾补建之间的
依赖未直说。本次没有复现一次真实 CST 材料报错，不将走读描述成实机复现。

修改后的独立走读覆盖以下五项，并在措辞修订后再次复核：

| 情景 | 观察到的决策 |
|---|---|
| 空工程先建 Quartz/Copper 实体、末尾定义材料 | 把材料创建前移，材料阶段通过后才提交几何。 |
| `new_material('Copper')` / `new_material('Quartz')` 无异常 | 识别预设名不支持和结构化失败，拒绝继续依赖几何。 |
| 安装库列出 Gold，工程没有定义 | 先导入或按明确物性创建；遵守会话显式路由。 |
| 工程同名 Quartz 的物性未知 | 核对真实定义后再复用，不凭同名覆盖。 |
| 仅使用 PEC | 直接复用内置材料，不创建 PEC 或空材料写入阶段。 |
